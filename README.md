# 鲁班工作台

常用工具放在同一个静态站点。二维码、条形码、订阅转换、密码生成和 PDF 去密码在浏览器内运行。智能隐私拼图、截图智能裁剪、去水印、足迹地图保留各自的独立入口。

| 工具 | 能做什么 |
| --- | --- |
| [二维码](tools/#mode=qr) | 文本、网址、Wi-Fi 或名片模板；四档纠错、颜色、PNG / SVG 导出。 |
| [条形码](tools/#mode=barcode) | Code 128、EAN-13、Code 39；EAN-13 输入 12 位时补校验位，输入 13 位时校验。 |
| [订阅转换](tools/#mode=clash) | 导入或粘贴 Clash / Mihomo 的 `proxies` 节点，与明文或 Base64 节点链接互转，显示逐节点跳过原因。 |
| [随机密码](tools/#mode=pass) | 使用 Web Crypto，按长度和字符类型生成；密码历史默认关闭，开启也只留在当前页面。 |
| [PDF 去密码](tools/pdf/) | 输入已知打开密码，或留空解除打印、复制限制。生成独立副本，单份最大 50 MB。 |

订阅转换只处理节点数据，不拉取订阅网址或 `proxy-providers`，也不迁移原配置的策略和规则。协议扩展与客户端支持有差异，请在目标客户端确认导入和连通性。Base64 可以直接还原，导出的文件应视为包含凭据。

二维码和条码内容可手动记在当前页面，订阅内容不写入浏览器存储。通过 HTTPS 首次打开且浏览器完成缓存后，四个内置工具可以断网重开；PDF 工具首次处理时加载 qpdf 引擎，缓存完成后可离线处理。独立应用有各自的缓存和联网要求。

## 预览与维护

运行 `python3 -m http.server 8787`，打开 [本机预览](http://127.0.0.1:8787/)。

首页是工具导航，`tools/` 放浏览器工具的界面和逻辑。运行时无需构建或服务器 API；发布时部署整个仓库，改动页面或脚本时更新 `sw.js` 的缓存版本。YAML 解析使用固定的 [js-yaml 5.5.0](https://github.com/nodeca/js-yaml) 浏览器包，许可证在 `tools/vendor/`。

回归验证（Node.js 24+）：`npm ci && npm test`。ZXing 独立回读二维码和三种条码；订阅用例使用示例节点，覆盖 IPv6、数字凭据、YAML 锚点、端口及传输选项。
